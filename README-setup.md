# AnonTalk — приватный чат (anontalk-secure-chat.html)

Один статический HTML-файл, дизайн в духе Telegram. Ключи вашего проекта Firebase уже вставлены — ничего редактировать не нужно, кроме правил доступа (шаг ниже).

## Перед загрузкой на хостинг — проверьте в консоли Firebase

Откройте https://console.firebase.google.com → ваш проект `chat2-3f11a`:

1. **Build → Authentication → Sign-in method → Anonymous** — должно быть включено (Enabled). Если ещё нет — нажмите, включите тумблер, сохраните
2. **Build → Realtime Database** — база должна существовать. Если ещё не создана — Create Database → любой регион → **test mode**
3. **Realtime Database → Rules** — вставьте и нажмите Publish:
```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
```

## Загрузка на хостинг

Загрузите `anontalk-secure-chat.html` на любой статический хостинг (Netlify, Vercel, GitHub Pages, обычный хостинг по FTP). **Важно: должен быть доступ по `https://` или `http://`, не открывайте файл двойным кликом с компьютера** — Firebase-авторизация не работает при локальном открытии (`file:///...`).

После загрузки: откройте адрес сайта → «Создать комнату» → введите ник → отправьте получившуюся ссылку (с `#/r/код` в конце) друзьям.

## Если что-то не работает

Ошибки теперь показываются прямо в интерфейсе (в окошке ввода ника) и в консоли браузера (клавиша **F12** → вкладка **Console**). Частые причины:

- **«Не удалось подключиться»** → не включена Anonymous-авторизация (см. пункт 1 выше) или файл открыт локально, а не через хостинг
- **Форма ника ничего не делает** → откройте консоль (F12), посмотрите на красный текст ошибки
- **Не работает запись голосового/видео** → сайт должен быть открыт по https; на http браузер не даёт доступ к микрофону/камере (кроме localhost)
- **«Permission denied» в консоли** → проверьте, что правила из пункта 3 опубликованы

## Ограничения (как и раньше)

- Не end-to-end шифрование — сообщения хранятся в Firebase в читаемом виде
- Комната открыта всем, у кого есть ссылка
- Запись голосового ограничена 30 сек, кружка — 12 сек (чтобы не упереться в бесплатный лимит Firebase); поменять — в файле ищите `MAX_SECONDS`
